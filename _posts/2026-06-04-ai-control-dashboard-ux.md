## 관제 UI의 핵심은 빠른 판단

관제 대시보드는 예쁜 화면보다 빠른 판단을 돕는 화면이어야 합니다. 사용자는 여러 카메라와 이벤트를 동시에 보면서 어떤 알람을 먼저 처리할지 결정합니다.

따라서 색상, 소리, 카드 크기, 정렬 방식은 모두 우선순위를 전달하는 방향으로 설계해야 합니다.

## 화면에 꼭 필요한 상태

| 상태 | 표시 이유 |
| --- | --- |
| 카메라 연결 상태 | 영상 장애와 실제 무이벤트를 구분 |
| 모델 동작 상태 | 추론 중단 여부 확인 |
| 알람 우선순위 | 긴급 이벤트를 먼저 처리 |
| 이벤트 처리 상태 | 미확인/확인/종료 흐름 관리 |
| threshold 설정 | 운영자가 민감도를 조정 |

## 다크 테마를 쓸 때

관제 화면은 장시간 보는 경우가 많아 다크 테마가 유리할 수 있습니다. 하지만 모든 것을 어둡게 만들면 알람 강조가 약해집니다.

배경은 낮은 대비로 두고, 위험 알람은 색과 위치, 모션을 함께 사용해 구분합니다. 단, 깜빡임은 피로도가 높으므로 정말 중요한 이벤트에만 제한적으로 사용해야 합니다.

## GIS 기반 UI

지도 기반 관제에서는 이벤트 위치와 카메라 방향이 중요합니다. 단순 마커보다 카메라 시야각, ROI, 알람 발생 지점을 함께 보여주면 현장 파악이 빨라집니다.
