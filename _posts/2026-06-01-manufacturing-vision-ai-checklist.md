## 왜 제조업 Vision AI는 일반 이미지 분류와 다른가

제조 현장의 이미지는 모델보다 촬영 조건이 먼저 성능을 흔드는 경우가 많습니다. 같은 제품이라도 조명 각도, 라인 속도, 카메라 해상도, 금속 표면 반사 때문에 입력 분포가 쉽게 바뀝니다.

특히 용접 비드, 금속 표면, 조립 부품 검사는 사람이 보기에도 애매한 경계가 많습니다. 그래서 모델 개발 전에 정상과 불량을 나누는 기준을 명확히 적어두는 것이 중요합니다.

## 데이터 수집 전 확인할 것

| 항목 | 확인 포인트 |
| --- | --- |
| 불량 정의 | 결함 유형별 판정 기준이 작업자마다 같은가 |
| 촬영 조건 | 조명, 초점, 노출, 카메라 위치가 고정되는가 |
| 해상도 | 학습 데이터와 운영 데이터의 해상도가 같은가 |
| 샘플 수 | 유형별 최소 수량과 희귀 불량 확보 계획이 있는가 |
| 라벨 정책 | 애매한 샘플을 정상/불량/보류 중 어디에 둘 것인가 |

## 모델 선택 방향

단순 정상/불량 판정이면 Image Classification부터 시작하는 것이 빠릅니다. 결함 위치까지 필요하면 Object Detection이나 Segmentation으로 넘어갑니다.

처음부터 복잡한 모델을 쓰기보다 ResNet, EfficientNet, ConvNeXt 같은 백본을 같은 데이터로 비교해 기준선을 만드는 편이 좋습니다. 모델 성능표에는 accuracy만 넣지 말고 불량 recall, 정상 false alarm, inference latency를 같이 기록해야 운영 판단이 가능합니다.

## 운영에서 자주 터지는 문제

HD로 학습하고 FHD로 테스트하면 성능이 흔들릴 수 있습니다. 리사이즈 방식이 달라지면 작은 결함의 픽셀 비율이 바뀌기 때문입니다. 고반사 금속은 하이라이트가 결함처럼 보이기도 해서 조명 확산, 편광 필터, 전처리 실험을 함께 봐야 합니다.

모델이 어디를 보고 판단했는지도 남겨야 합니다. Grad-CAM 같은 XAI 시각화는 성능 지표만으로 알 수 없는 편향을 찾는 데 도움이 됩니다.

## 실험 로그에 남길 것

데이터 버전, 촬영 조건, 해상도, 라벨 기준, 모델 백본, threshold, 오탐/미탐 사례 이미지를 한 번에 묶어 기록합니다. 제조업 AI 검사는 "정답률이 높다"보다 "현장에서 같은 조건으로 반복 가능하다"가 더 중요합니다.
