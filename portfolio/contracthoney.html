Background

왜 계약서 분석 AI인가

계약서에는 법률을 위반하는 위법조항과, 한쪽 계약자에게 불리하게 작용하는 독소조항이 숨어 있는 경우가 많습니다. 프랜차이즈·온라인 플랫폼 약관의 불공정 조항, 프리랜서 계약의 독소조항 등 실제 피해 사례가 끊이지 않지만, 일반 사용자가 이를 일일이 식별하기는 어렵습니다. 계꿀은 이 진입장벽을 AI로 낮추는 것을 목표로 했습니다.

위법조항 법률을 위반한 조항
독소조항 계약자에게 불리한 영향을 미치는 조항
Features

핵심 기능

01
위법·독소조항 검출

문장 단위로 위법·독소 여부를 확률로 판별하고, 위반하는 법 조항(조·항·호)까지 예측합니다.

02
계약서 요약

조 단위로 핵심 내용을 자연어로 요약해 긴 계약서를 빠르게 파악할 수 있습니다.

03
버전 관리

계약서 버전을 저장하고 변경된 조항을 비교해 수정 이력을 추적합니다.

04
법령·표준계약서 자료실

관련 법령과 공정위 표준계약서를 조회할 수 있는 자료실과 Q&A를 제공합니다.

Architecture

시스템 아키텍처

3-Tier 구조로 설계했습니다. 클라이언트는 Next.js, 애플리케이션·AI 추론은 FastAPI, 데이터는 Azure Database(MySQL)와 계약서 파일용 Azure Storage로 분리했고, 전체를 Docker 컨테이너로 Azure 서버에 배포했습니다.

Service Flow

서비스 플로우

이메일 인증 기반 회원가입과 4시간 만료 토큰으로 계정을 관리하고, 로그인 후 계약서를 업로드하면 AI 서버가 문장을 분리해 위법·독소조항 판별과 요약을 수행한 뒤 결과를 DB에 저장하고 분석 로그·버전 비교 화면으로 보여줍니다.

AI

계약서 분석 AI 구성

한국어 계약서·법률 도메인에 맞춰 여러 사전학습 모델(KLUE-BERT, KoBERT, KoELECTRA, KLUE-RoBERTa, XLM-RoBERTa 등)을 비교·학습한 뒤, 작업별로 최적 모델을 선정했습니다.

위법 식별
KoBERT

성능이 가장 우수해 선정. 임계값 31.10%(Precision-Recall 기반).

독소 식별
KoELECTRA

독소조항 판별 성능 최상위. 임계값 58.67%.

위반 법률 예측
KoBERT + 코사인 유사도

위반 법 조(條) 예측 후, 코사인 유사도로 세부 항·호를 매칭.

요약

두 모델을 비교 학습. eval accuracy 0.9333, perplexity 1.478.
