Overview

모델의 예측을 실제 결제 승인과 차단까지 연결했습니다

Fraudi는 온라인 쇼핑몰에서 결제가 발생하면 거래 정보를 실시간으로 분석해 정상 거래는 승인하고 이상 거래는 차단하는 FDS(Fraud Detection System) 프로젝트입니다. 데이터 수집·정제, 피처 엔지니어링, 불균형 완화, 모델 학습과 튜닝, FastAPI 추론 API, React Native 앱 연동까지 전체 파이프라인을 구현했습니다.

Problem & EDA

극단적인 클래스 불균형 속에서 사기 신호를 찾다

사기 거래가 정상 거래보다 현저히 적어 정확도만으로는 탐지 성능을 판단하기 어려웠습니다. EDA를 통해 거래 금액, 카테고리, 시간대를 주요 변수로 확인했고, 새벽의 위험 증가와 온라인·오프라인 카테고리별 패턴을 피처에 반영했습니다. 식별자와 설명력이 낮은 위치 원시값은 제거하고 사용자 거래 빈도와 거래 간격, 순환형 시간 변수, 고위험 시간대 변수를 새로 만들었습니다.

01
시간 리듬

hour를 사인·코사인으로 변환하고 고위험 시간대 여부를 파생 변수로 생성했습니다.

02
사용자 행동

1·7·30일 거래 빈도, 거래 간격, 나이 등 평소 소비 패턴과의 차이를 표현했습니다.

03
지역 상호작용

city와 state를 결합해 같은 도시명도 지역에 따라 다른 거래 특성을 갖도록 했습니다.

04
안전한 범주 인코딩

job·city_state에 OOF 스무딩 타깃 인코딩을 적용해 누수와 과적합을 줄였습니다.

Imbalanced Data

놓치는 사기를 줄이기 위해 CTGAN을 선택했습니다

VAE와 CTGAN으로 소수 클래스 합성 품질을 비교했습니다. CTGAN은 VAE보다 높은 재현율 83% 대 70%를 보여, 오탐보다 미탐 비용이 큰 FDS의 목표에 더 적합했습니다. 스무딩을 OOF 방식으로 먼저 적용해 타깃 누수를 막고, Optuna로 생성기·판별기 학습률과 배치 크기를 조정한 뒤 100,000건의 합성 사기 거래를 학습 데이터에 보강했습니다.

CTGAN 범주형·연속형이 섞인 테이블 데이터의 분포를 보존
OOF Encoding 검증 폴드의 정답을 보지 않는 타깃 인코딩으로 누수 방지
Model

서로 다른 부스팅 모델의 판단을 스태킹했습니다

LightGBM의 속도, XGBoost의 정규화, CatBoost의 범주형 일반화 성능을 결합했습니다. 3-fold OOF 예측값을 새 학습 데이터로 만들고 Logistic Regression 메타 모델이 각 베이스 모델의 신뢰도를 학습하도록 구성했습니다. Optuna·Grid Search·Random Search로 모델별 파라미터를 탐색하고, 최종적으로 임계값을 0.12로 조정해 사기 클래스 Precision과 Recall의 균형을 개선했습니다.

Service Flow

결제 요청 사이에 FDS를 삽입한 시뮬레이션

사용자가 장바구니에서 결제를 요청하면 앱이 거래 정보를 서버로 전송하고 FastAPI 모델 서버가 이상 확률을 반환합니다. 정상 거래는 주문 완료로 이어지고, 임계값을 넘은 거래는 즉시 차단됩니다. 사용자는 마이페이지의 이상거래 분석에서 정상·이상 비율과 거래별 판정 이력을 다시 확인할 수 있습니다.

Product UI

탐지 모델을 검증할 수 있는 모바일 쇼핑몰

React Native와 TypeScript로 홈, 카테고리, 상품 상세, 장바구니, 주문 내역, 리뷰와 계정 관리까지 구현했습니다. API 대기 중에는 진행 상태를 명확히 보여주고, 화면 재진입 시 이벤트 기반으로 데이터를 갱신하며, 긴 거래 이력은 페이지네이션으로 점진적으로 불러오도록 구성했습니다.

Architecture

앱·비즈니스 API·모델 서버를 분리했습니다

React Native 앱은 Spring Boot API와 통신하고, 결제 시 FastAPI 모델 서버에 추론을 요청합니다. 거래·회원·상품 데이터는 MySQL에 저장했으며 AWS EC2에서 Docker 컨테이너로 서비스하고 GitHub Actions로 배포 흐름을 구성했습니다.
